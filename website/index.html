GitHub 릴리스와 설치 파일 ↗

macOS 15 이상 · Apple Silicon
M1 이후 M 시리즈용입니다. Intel Mac·Windows 설치본은 없습니다. 실제 확인 환경은 macOS 15.6.1 / M1 Pro입니다.

  1. 공식 릴리스에서 DMG 받기

    Assets의 Swallow-0.1.0-macOS-arm64-unsigned.dmg를 받으세요. Source code ZIP은 설치 파일이 아닙니다.

  2. 응용 프로그램 폴더로 복사하기

    기존 앱은 ⌘Q로 종료하고 기록을 백업하세요. DMG를 열어 Swallow.app을 Applications 폴더로 드래그합니다.

  3. 디스크 이미지를 추출하고 실행하기

    Finder에서 Swallow 디스크 이미지를 추출한 뒤, 응용 프로그램 폴더의 Swallow를 여세요. Node·npm·Xcode는 필요 없습니다.

Developer ID 서명·Apple 공증이 없습니다.

Apple이 개발자 신원이나 이 배포본의 악성코드 검사를 확인해 준 버전이 아닙니다. 출처를 확신할 수 없다면 설치를 중단하세요.

“개발자를 확인할 수 없음” 경고가 표시되나요?

공식 릴리스에서 받은 파일인지 확인하세요. 실행을 허용하려면 경고를 닫은 뒤 시스템 설정 → 개인정보 보호 및 보안 → 보안 → 그래도 열기에서 앱 이름이 Swallow인지 확인합니다. 다시 뜨는 창에서도 실행 여부를 직접 판단하세요. 관리되는 Mac에서는 허용이 제한될 수 있습니다.

Apple의 공식 앱 보안 안내 ↗

“앱이 손상되었습니다”, “컴퓨터를 손상시킵니다” 또는 악성코드 발견 경고라면 실행을 중단하세요. 공식 릴리스에서 다시 받고 체크섬을 확인해 주세요. 계속되면 오류 문구와 macOS 버전을 이슈로 알려주세요.

다운로드한 파일 확인하기

같은 릴리스의 SHA256SUMS.txt도 같은 폴더에 받으세요. 기본 다운로드 폴더를 썼다면 터미널에서 아래 명령을 실행합니다.

cd ~/Downloads
shasum -a 256 -c SHA256SUMS.txt

DMG 파일명 뒤에 OK가 나와야 합니다. 파일이 다르면 설치하지 마세요. 체크섬은 파일 일치 확인이며 Apple 공증을 대신하지 않습니다.

Windows·iOS·Android 버전도 차차 공개할 예정입니다. 각자의 기기에서 작은 시작을 할 수 있도록 지원 범위를 넓혀가겠습니다.

Windows·iOS·Android를 플랫폼별 개발과 실행 검증을 거쳐 순차적으로 공개할 예정입니다.
AI 연결 확장
Ollama 외에도 GPT 계열 SDK와 다른 AI 제공자를 연결하는 버전을 준비할 예정입니다.
공개 안내
지원 범위·연결 방식·이용 조건과 데이터 전송 범위는 각 버전 공개 시 GitHub에서 안내하겠습니다.

현재는 macOS Apple Silicon 미리보기와 Ollama 로컬 AI 연결을 제공합니다. 추가 플랫폼·AI 연결은 향후 계획이며, 공개 일정은 아직 확정되지 않았습니다.
