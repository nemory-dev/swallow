# Swallow

원문을 작은 부분부터 읽고, 내 답변과 요점노트를 남기는 개인 학습용 macOS 데스크톱 앱입니다. 텍스트·Markdown·공개 문서 링크·PDF를 가져와 읽고, 로컬 음성으로 듣고, 회상·복습 기록을 저장할 수 있습니다.

자체 작성 코드와 문서는 [MIT 라이선스](LICENSE)를 따릅니다. 모든 기능은 무료이며 기능 유료 전환을 하지 않습니다. 후원은 나중에 별도로 도입합니다. 현재는 **소스 공개 준비 단계**이며 설치본·스토어 배포·자동 업데이트 feed를 제공하지 않습니다.

## 개발 실행

macOS Apple Silicon, Node.js 24 LTS와 npm을 권장합니다. manifest 요구는 Node `>=22.12.0`이며 의존성은 `package-lock.json`으로 고정합니다. PDF helper 빌드에는 Xcode Command Line Tools가 필요합니다. 설치된 도구를 확인하고 필요한 경우 직접 준비하세요.

저장소 루트에서:

```sh
npm ci
npm run dev
```

`npm ci`는 네트워크로 패키지와 Electron 바이너리를 내려받습니다. `npm run dev`는 빌드 후 데스크톱 앱과 `127.0.0.1:5173` 개발 서버를 엽니다. renderer 변경은 자동 반영되며 `electron/`, `src/shared/`, `src/learning/` 변경은 앱 재시작이 필요합니다.

```sh
npm start          # 빌드 후 데스크톱 실행
npm run preview   # 브라우저 미리보기
```

브라우저 미리보기는 별도 사이트 저장소에서 읽기·답변·노트·공개 링크·로컬 음성을 제공합니다. AI와 PDF 가져오기는 데스크톱 기능입니다. `npm run build`는 개발용 출력을 생성하며 설치본을 만들지 않습니다.

## 학습 흐름

1. 텍스트·Markdown·공개 URL 또는 PDF를 가져옵니다. 읽기와 답변·노트 저장에는 AI가 필요하지 않습니다.
2. **공부 시작**으로 현재 위치의 작은 원문부터 진행합니다. AI가 연결됐다면 짧은 설명·더 쉽게·예시를 선택할 수 있습니다.
3. 확인 질문에 내 말로 답합니다. **아직 모르겠어요**는 현재 답변을 보존하고 재설명으로 돌아갑니다. AI 실패 시에도 답변과 원문은 유지합니다.
4. **요점노트 저장**으로 AI 설명 또는 원문 발췌, 실제 답변, 미해결 질문과 출처를 남깁니다. 같은 구간은 기존 노트를 갱신하며 기존 기록을 언어 변경만으로 자동 번역하지 않습니다.
5. **한 부분 더** 또는 **오늘은 여기까지**를 선택합니다. 재실행 후 저장된 학습을 이어갈 수 있습니다. 자유 읽기·회상·복습·자료/노트 검색·폴더도 사용할 수 있습니다.

확인 질문 피드백은 현재 질문과 답변을 원문에 대조한 참고 설명이며 자동 채점이나 이해도 보장이 아닙니다. AI 결과는 원문과 비교하세요. PDF 그림은 원본 페이지로 확인하고, 현재 로컬 AI는 PDF 이미지 설명을 지원하지 않습니다. PDF 읽기·로컬 OCR·메모·원문 노트는 계속 사용할 수 있습니다.

## 학습자료 번역

자유 읽기 또는 함께 공부의 **원문 번역**에서 한국어/영어를 선택한 뒤 현재 읽기 구간이나 전체 자료를 번역합니다. 번역 언어는 앱 표시·학습 설명 언어와 독립적입니다. 원문과 번역을 나란히 대조할 수 있으며 원문·답변·노트·읽기 위치는 바꾸지 않습니다. 함께 공부의 현재 구간 번역은 화면의 작은 설명 부분이 속한 읽기 구간 전체를 대상으로 합니다.

번역은 연결한 Ollama 모델로 작은 부분을 순서대로 처리합니다. 전체 자료는 완료한 구간부터 저장하고 취소·실패 후 같은 모델·원문·언어·지침 버전으로 다시 실행하면 완료 구간을 재사용합니다. 저장된 번역은 서버 연결 없이도 볼 수 있습니다. 모델을 바꾸면 다음 명시적 번역 요청에서 새로 생성하며, 언어 선택만 바꾸어 자동 요청하지 않습니다. 긴 논문은 시간이 걸릴 수 있으며 취소할 수 있습니다.

PDF는 추출/OCR 텍스트만 번역하며 빈 페이지는 건너뜁니다. 그림·표·수식의 배치를 복원하지 않습니다. 로컬 모델이 문장을 누락하거나 전문용어·코드·수식을 잘못 번역할 수 있으므로 원문과 대조하세요. 번역문을 정답이나 학습 평가 근거로 자동 사용하지 않습니다. 브라우저 미리보기에서는 새 번역 생성이 지원되지 않습니다.

## 로컬 AI

현재 연결은 **사용자가 이미 준비한 Ollama 텍스트 모델**입니다. 구독 로그인·SDK·브랜드·외부 AI API 키는 포함하지 않습니다. 서버/모델 설치·다운로드·유료 전환을 앱이 자동 수행하지 않습니다.

앱의 로컬 AI 연결 패널에서 `127.0.0.1` 또는 `::1`과 포트를 입력하고 서버 연결 → 모델을 직접 선택하세요. 기본 포트는 11434입니다. 재시작 후 연결 주소와 모델 선택은 보존하지만 자동 서버 조회/추론하지 않으므로 연결 상태를 다시 확인합니다.

- API 계약 fixture 범위는 Ollama **0.12.0 / 0.24.0 / 0.40.4**입니다. 다른 버전은 확인 전 차단하며 구버전으로 내릴 것을 권장하지 않습니다. 실제 설치 버전이 다르면 별도 호환 검증이 필요합니다.
- GGUF 텍스트 모델의 digest·completion·context·remote metadata를 요청 전에 확인합니다. cloud·원격·확인 불가 모델, 이미지 요청과 임의 서버 URL은 거절합니다.
- 현재 원문·질문·답변 등을 선택한 로컬 서버로 보냅니다. 실패·시간 초과·잘못된 JSON/인용·취소 시 기존 기록을 보존하고 다른 제공자나 유료 API로 자동 전환하지 않습니다.
- localhost와 metadata 검사만으로 완전 오프라인을 보장하지 않습니다. Ollama cloud 기능·서버 로그·프록시 설정은 사용자가 관리하며 실제 오프라인 동작·모델 품질·메모리와 지연시간은 별도 검증이 필요합니다.

모델이 없거나 서버가 꺼져 있어도 AI 없는 학습은 사용할 수 있습니다. 다른 버전에 저장한 모델 선택·설명·답변·노트는 지우지 않습니다. 지금 제공하지 않는 과거 모델은 사용 불가로 유지하고 사용자가 새 로컬 모델을 직접 선택합니다.

## 한국어와 영어

앱 표시 언어와 새 학습 구간의 설명 언어를 독립적으로 설정합니다. 현재 구간은 시작할 때의 설명 언어를 유지하며 변경된 기본값은 다음 구간부터 적용합니다. 기존 원문·질문·답변·노트·복습 시각을 자동 번역하거나 덮어쓰지 않습니다. UI 언어 변경만으로 AI 요청을 실행하지 않습니다.

## 저장·백업·삭제

기본 macOS 저장 위치는 `~/Library/Application Support/Swallow`이며 `SWALLOW_DATA_DIR`에 절대 경로를 지정하면 달라집니다. SQLite·PDF 복사본·초안·백업은 앱 자체에서 암호화하지 않습니다. 문서 삭제 후 PDF·미저장 PDF 메모·legacy 파일·백업은 남을 수 있습니다. 보관은 압축 저장이며 삭제가 아닙니다.

백업은 앱을 완전히 종료한 뒤 DB·PDF·필요한 legacy/백업을 함께 안전한 로컬 위치에 복사하세요. 현재 저장소를 빈 파일로 덮어쓰거나 인증/모델 파일을 임의 삭제하지 마세요. 정확한 전송·삭제 범위와 관리 절차는 [개인정보 안내](PRIVACY.md)를 확인하세요.

## 검증과 공개 소스 준비

```sh
npm run check        # 전체 테스트 + PDF/타입/Vite/Electron/preload 빌드
npm run source:check
npm run source:prepare
```

`source:check`는 working tree의 명시적 소스 목록에서 구독 의존성·금지 파일·symlink·제한된 민감 패턴과 공개 문서 링크를 확인합니다. `source:prepare`는 통과한 파일만 `artifacts/public-source/`의 새 폴더에 복사하고 파일별 SHA-256 manifest를 만듭니다. Git 이력·node_modules·사용자 DB·인증·내부 계획·설치본은 복사하지 않으며 commit/push/업로드도 하지 않습니다. 테스트/빌드와 최종 사용자 검토는 별도이며, 패턴 검사가 모든 비밀을 증명하는 것은 아닙니다.

Electron UI 검증 스크립트는 선택 도구 Playwright를 사용합니다. 이미 설치된 모듈의 절대 경로를 `SWALLOW_PLAYWRIGHT_MODULE`로 지정할 수 있습니다. 합성 localhost 서버/임시 저장소 시험과 실제 모델·설치본 검증은 구분합니다.

빌드 후 기존 Playwright로 UI 전체 회귀를 실행하려면:

```sh
export SWALLOW_PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs
(for flow in study folders update ollama i18n translation pdf; do
  node "scripts/test-${flow}-ui.mjs" || exit 1
done)
```

이 시험은 임시 앱 저장소와 합성 AI/업데이트 응답, 저장소 안의 PDF 예제를 사용합니다. 계정·모델 다운로드·실제 업데이트 설치는 하지 않습니다. 공부 UI 시험은 설치된 macOS 음성이 사용 가능하면 읽어 주기 시작/중지를 확인합니다. localhost/GUI/OCR 사용 권한이 필요하며 실패한 시험을 제외해 통과 처리하지 마세요.

문서를 추가하는 중 대상 폴더가 삭제됐다면 입력을 유지하고 다른 폴더를 선택하라는 안내를 표시합니다. 중복 폴더 이름도 다른 이름으로 바꿀 수 있도록 안내합니다. 업데이트 시험은 선택적인 음성 목록 조회가 끝난 뒤 설치를 검증하며, 진행 중 작업·답안/메모 저장 실패 시 설치를 막는 보호는 유지합니다.
