# Swallow

원문을 작은 부분부터 읽고, 내 답변과 요점노트를 남기는 개인 학습용 macOS 데스크톱 앱입니다. 텍스트·Markdown·공개 문서 링크·PDF를 가져와 읽고, 로컬 음성으로 듣고, 회상·복습 기록을 저장할 수 있습니다.

**[Swallow 소개 사이트](https://nemory-dev.github.io/swallow/)**에서 실제 앱 화면, 사용 흐름과 Mac 설치 안내를 볼 수 있습니다.

자체 작성 코드와 문서는 [MIT 라이선스](LICENSE)를 따릅니다. 모든 기능은 무료이며 기능 유료 전환을 하지 않습니다. 선택적인 일회성 후원을 준비하고 있으며, 후원자 전용 혜택은 제공하지 않습니다. macOS Apple Silicon용 **[v0.1.0 미리보기 설치본](https://github.com/nemory-dev/swallow/releases/tag/v0.1.0)**을 공개했습니다. 스토어 배포·자동 업데이트 feed는 제공하지 않습니다. GitHub의 **Code → Download ZIP**은 소스 파일이며 설치 프로그램이 아닙니다.

## 앞으로 공개할 버전

Swallow는 더 많은 기기와 AI 연결 방식으로 확장할 예정입니다.

- **Windows·iOS·Android:** 플랫폼별 개발과 실행 검증을 거쳐 순차적으로 공개할 예정입니다.
- **AI 연결 확장:** Ollama 외에도 GPT 계열 SDK와 다른 AI 제공자를 연결하는 버전을 준비할 예정입니다. 지원 제공자·연결 방식·이용 조건과 데이터 전송 범위는 각 버전 공개 시 안내하겠습니다.

현재 공개된 설치본은 **macOS Apple Silicon용 v0.1.0 미리보기**이며, AI 연결은 **Ollama 로컬 텍스트 모델**을 지원합니다. 위 내용은 향후 계획이며 추가 플랫폼·AI 연결은 아직 제공되지 않습니다. 구체적인 공개 일정과 지원 범위는 검증이 끝나는 대로 이 저장소와 [소개 사이트](https://nemory-dev.github.io/swallow/)에서 안내하겠습니다.

## DMG로 설치하기 — 릴리스 공개 후

대상은 **macOS 15.0 이상 / Apple Silicon(M1 이후 M 시리즈)**입니다. Intel Mac·Windows용 설치본은 없습니다. 최소 대상은 15.0으로 설정했으며 실제 확인한 기기는 macOS 15.6.1 / M1 Pro입니다. 다른 기기와 macOS 버전에서의 동작을 보장하지 않습니다. **설치본 실행에는 소스 코드·Node·npm·Xcode가 필요하지 않습니다.** Ollama도 AI 기능을 선택할 때만 필요합니다.

미리보기 설치본은 로컬 ad-hoc 서명으로 앱 리소스 무결성 검사를 통과했습니다. macOS 15.6.1에서 Chrome으로 새로 받은 DMG의 SHA-256과 자동 다운로드 격리 속성을 확인하고, Applications 설치·아래의 앱별 허용·첫 학습·종료 후 재실행을 검증했습니다. 설치 사본의 PDF 표시·한영 OCR·노트 보존도 확인했습니다.

1. 이 저장소의 **[v0.1.0 미리보기 릴리스](https://github.com/nemory-dev/swallow/releases/tag/v0.1.0)**를 엽니다.
2. **Assets**에서 `Swallow-0.1.0-macOS-arm64-unsigned.dmg`를 받습니다. `Source code (zip)`·`Source code (tar.gz)`는 설치본이 아닙니다.
3. 기존 Swallow가 켜져 있다면 `⌘Q`로 종료합니다. 이미 학습 기록이 있다면 [저장·백업·삭제](#저장백업삭제)에 따라 먼저 백업하세요. 개발 실행과 설치본은 같은 기본 저장 위치를 사용합니다.
4. DMG를 두 번 클릭하고, 안의 **Swallow.app을 Applications 폴더로 드래그**합니다. 설치 권한을 묻는 경우 본인이 권한을 확인합니다. 기존 앱을 교체할 때에는 앱을 완전히 종료한 뒤 진행하세요.
5. Finder에서 Swallow 디스크 이미지를 추출한 뒤 **응용 프로그램 → Swallow**를 엽니다. DMG 안에서 계속 실행하지 마세요.
6. 아래 보안 안내를 확인한 뒤 [첫 학습 확인](#첫-학습-확인)으로 진행합니다.

### 서명·공증 없는 미리보기의 보안 경고

이 앱에는 **Swallow 개발자의 Developer ID 서명과 Apple 공증이 없습니다.** Apple이 개발자 신원이나 이 배포본의 악성코드 검사를 확인해 준 버전이 아닙니다. 실행 허용 여부는 사용자가 판단해야 하며, 불편하거나 출처를 확신할 수 없다면 설치를 중단하세요.

공식 저장소에서 받은 파일이고 “개발자를 확인할 수 없음” 또는 “악성 코드가 없음을 확인할 수 없음” 경고가 나온다면 **완료**로 경고를 닫습니다. **시스템 설정 → 개인정보 보호 및 보안 → 보안 → 그래도 열기**에서 차단된 앱 이름이 Swallow인지 확인하고, 다시 뜨는 확인 창에서 **그래도 열기** 또는 **열기**를 선택할 수 있습니다. Mac 암호나 Touch ID를 요구할 수 있습니다. 회사·학교에서 관리하는 Mac에서는 이 선택이 막힐 수 있습니다. [Apple의 공식 안내](https://support.apple.com/ko-kr/102445)

**“앱이 손상되었습니다”, “컴퓨터를 손상시킵니다” 또는 악성코드를 발견했다는 경고라면 실행을 중단하세요.** 공식 릴리스에서 다시 내려받고 아래 체크섬을 확인한 뒤, 계속되면 오류 문구와 macOS 버전을 [이슈](https://github.com/nemory-dev/swallow/issues)로 알려 주세요. “그래도 열기”가 없거나 계속 차단되면 실행을 강제하지 마세요. Gatekeeper 전체 해제, quarantine 속성 삭제, 설치 후 사용자의 임의 재서명은 설치 절차에 포함하지 않습니다. 보안 경고가 없는 로컬 실행 성공만으로 다른 기기의 다운로드 후 설치 성공을 보장하지 않습니다.

### 받은 파일 확인하기 — 선택 사항

DMG와 같은 릴리스의 `SHA256SUMS.txt`를 같은 폴더에 받은 뒤, 그 폴더에서 다음을 실행합니다. 기본 다운로드 폴더를 사용했다면:

```sh
cd ~/Downloads
shasum -a 256 -c SHA256SUMS.txt
```

DMG 파일명 뒤에 `OK`가 나와야 합니다. 같은 이름의 이전 후보를 받은 적이 있다면 새 다운로드 파일인지도 확인하세요. 다르거나 파일이 없다는 오류가 나면 설치하지 말고 파일명·다운로드 완료 여부를 확인하세요. SHA-256은 게시된 파일과 같은지 확인하는 값이며 Apple 공증이나 앱의 안전성 보증을 대신하지 않습니다.

## 소스로 실행하기 — 개발자용

지원하는 개발용 Node 버전은 **24 LTS (`24.x`)**이며 `.nvmrc`도 24를 지정합니다. Node 22·25·26은 지원 범위에 포함하지 않습니다. 의존성은 `package-lock.json`으로 고정합니다. 앱과 PDF helper의 최소 대상은 **macOS 15.0 / Apple Silicon (arm64)**입니다. 실제 확인한 환경은 **macOS 15.6.1 / Apple Silicon**이며 macOS 15.0 기기·다른 macOS 버전·Intel Mac·Windows는 아직 검증하지 않았습니다.

먼저 필요한 도구를 준비하세요.

1. [Node.js 공식 다운로드](https://nodejs.org/en/download)에서 **24 LTS / macOS arm64**와 npm을 설치합니다. 이미 nvm을 사용한다면 저장소를 받은 뒤 `nvm install`과 `nvm use`로 `.nvmrc`의 버전을 선택할 수 있습니다.
2. Git과 PDF helper 빌드에 필요한 Xcode Command Line Tools를 준비합니다. 개발 도구가 없다면 `xcode-select --install`을 실행하고 설치 완료를 기다리세요. 이미 Xcode가 설치됐다면 기존 도구를 사용합니다. 검증 기기는 Xcode 전체 설치 환경이며 Command Line Tools만 설치한 환경은 아직 별도로 확인하지 않았습니다.
3. 터미널을 다시 열어 도구와 버전을 확인합니다.

```sh
git --version
node --version          # v24.x
npm --version
node -p "process.arch"  # arm64
xcode-select -p
xcrun --find swiftc
```

새 작업 폴더에서 소스를 받아 실행합니다. 이미 저장소를 받았다면 해당 폴더로 이동해 `npm ci`부터 실행하세요.

```sh
git clone https://github.com/nemory-dev/swallow.git
cd swallow
npm ci
npm start
```

`npm ci`는 네트워크로 패키지를 받습니다. 고정된 Electron 44는 **첫 실행 때 바이너리를 별도로 내려받을 수 있어** 최초 실행에도 네트워크가 필요합니다. 미리 다운로드하려면 `npm ci` 뒤에 `npx install-electron --no`를 실행하세요. [Electron 공식 설치 안내](https://www.electronjs.org/docs/latest/tutorial/installation)

`npm start`는 PDF helper와 앱을 빌드한 뒤 개발 서버 없이 데스크톱 앱을 엽니다. 앱 창이 나타나면 아래 첫 학습으로 진행하세요.

## 첫 학습 확인

설치본과 소스 실행에서 같은 순서로 확인합니다. 로그인이나 Ollama 설치는 필요하지 않습니다.

1. **짧은 예제 문서로 시작하기 → 공부 시작**을 선택합니다.
2. **이번 부분 원문 보기**를 펼쳐 원문을 읽고 **한 가지 질문에 답해보기 →**를 선택합니다.
3. 내 답변을 적고 **답변 저장하고 요점노트 보기 → 요점노트 저장**을 선택합니다.
4. **한 부분을 공부하고 노트로 남겼어요.**, **저장한 요점노트 · 1개**가 보이면 성공입니다.
5. `⌘Q`로 앱을 완전히 종료하고 **응용 프로그램 → Swallow**로 다시 열어 문서·답변·요점노트가 남아 있는지 확인합니다. 소스 실행을 사용했다면 `npm start`로 다시 엽니다.

로컬 AI 연결은 첫 학습 이후에 선택할 수 있습니다. [로컬 AI 안내](#로컬-ai)를 참고하세요.

## 개발과 브라우저 미리보기

```sh
npm run dev       # 빌드 후 데스크톱 앱 + 개발 서버
npm run preview   # 브라우저 미리보기
```

두 명령은 각각 `127.0.0.1:5173` 개발 서버를 사용하므로 함께 실행하지 마세요. `npm run dev`에서는 renderer 변경이 자동 반영되며 `electron/`, `src/shared/`, `src/learning/` 변경은 앱 재시작이 필요합니다. 개발 서버만 실행 중이라면 해당 터미널에서 `Ctrl+C`로 종료합니다.

브라우저 미리보기는 별도 브라우저 저장소에서 읽기·답변·노트·공개 링크·로컬 음성을 제공합니다. 데스크톱에 저장한 기록과 공유하지 않으며, AI 생성과 PDF 가져오기는 데스크톱 기능입니다. `npm run build`는 개발용 출력을 생성하며 설치본을 만들지 않습니다.

## macOS Apple Silicon용 로컬 패키지 만들기

위 개발 도구와 `npm ci`를 준비한 **macOS 15 이상 / Apple Silicon / Node 24**에서 실행합니다.

```sh
npm run package:mac:arm64  # 빌드 후 Swallow.app 생성
npm run make:mac:arm64     # 빌드 후 Swallow.app + DMG 생성
```

각 명령은 `artifacts/macos/` 아래 새 출력 폴더를 만들고 완료 시 정확한 경로를 출력합니다. 두 명령 모두 빌드를 포함하므로 DMG까지 필요하면 두 번째 명령만 실행하세요. 최초 패키징은 Electron 바이너리를 내려받기 위해 네트워크가 필요할 수 있습니다.

생성한 `Swallow.app`을 별도 폴더로 복사해 실행하거나, 로컬 DMG를 열어 `Swallow.app`을 `Applications`로 옮길 수 있습니다. 완성된 앱에는 Electron과 PDF helper가 들어 있으므로 실행할 때 소스 폴더·Node·npm·Xcode·개발 서버가 필요하지 않습니다. Ollama는 AI를 선택적으로 사용할 때만 별도로 준비합니다. 앱을 옮겨도 학습 기록은 [기본 저장 위치](#저장백업삭제)에 남습니다. 개발 앱과 같은 저장 위치를 사용하므로 두 앱을 동시에 열지 말고, 별도 시험에는 절대 경로의 `SWALLOW_DATA_DIR`를 사용하세요.

현재 산출물은 **Developer ID 미서명·Apple 미공증 미리보기**입니다. 내부 파일이 바뀌지 않았는지 확인하는 인증서 없는 로컬 ad-hoc 서명은 포함합니다. 이는 개발자 신원이나 앱 안전성을 보증하지 않으며, 파일명의 `unsigned`는 Developer ID 서명·공증이 없다는 뜻입니다. 패키징 명령 자체는 GitHub 업로드·릴리스 공개·자동 업데이트 feed 생성을 수행하지 않습니다. 공개 미리보기 설치본은 [v0.1.0 릴리스](https://github.com/nemory-dev/swallow/releases/tag/v0.1.0)에서 제공합니다. 다운로드한 사본에서는 macOS가 실행을 막을 수 있으므로 [설치와 보안 경고 안내](#dmg로-설치하기--릴리스-공개-후)를 먼저 확인하세요. 패키징 절차와 검증 명령은 [기여 안내](CONTRIBUTING.md#macos-패키징-검증)를 참고하세요.

## 실행이 막힐 때

| 증상 | 확인과 복구 |
| --- | --- |
| `node`·`npm`을 찾지 못하거나 Node 버전이 다름 | Node 24 LTS 설치/선택 후 터미널을 다시 열고 `node --version`을 확인하세요. `npm ci`가 경고만 표시해도 지원 범위 밖의 Node로 계속 진행하지 마세요. |
| `No such built-in module: node:sqlite` | 먼저 Node 24인지 확인한 뒤 `npm run check`를 다시 실행하세요. Node 22용 실험 플래그는 현재 지원 절차가 아닙니다. |
| `xcrun` 또는 PDF helper 빌드 실패 | `xcode-select -p`, `xcrun --find swiftc`를 확인하세요. 도구 설치가 끝난 뒤 `npm run build`를 다시 실행합니다. |
| `Downloading Electron binary...`에서 오래 기다림 | 최초 다운로드일 수 있습니다. 네트워크와 GitHub 다운로드 접근을 확인한 뒤 다시 실행하거나 `npx install-electron --no`로 다운로드 단계를 따로 실행하세요. |
| 개발 서버가 열리지 않음 | 같은 프로젝트의 `dev`·`preview` 중복 실행을 확인하고 해당 터미널에서 `Ctrl+C`로 종료하세요. 첫 체험에는 `npm start`를 사용할 수 있습니다. |
| Playwright 모듈을 찾지 못함 | 앱 실행에는 필요 없는 UI 검증 도구입니다. [기여 안내의 UI 검증 준비](CONTRIBUTING.md#ui-검증-준비)를 참고하세요. |
| AI 연결 또는 앱 업데이트가 준비되지 않았다고 표시됨 | AI 없는 학습은 계속 사용할 수 있습니다. 로컬 AI는 사용자가 별도 준비하며, 현재 자동 업데이트 feed는 제공하지 않습니다. |

실행 문제를 문의할 때는 Node/npm 버전, macOS/CPU, 재현 순서와 개인정보를 지운 오류를 알려 주세요. 사용자 DB·PDF·학습 원문·토큰을 첨부하지 마세요.

## 학습 흐름

1. 텍스트·Markdown·공개 URL 또는 PDF를 가져옵니다. 읽기와 답변·노트 저장에는 AI가 필요하지 않습니다.
2. **공부 시작**으로 현재 위치의 작은 원문부터 진행합니다. AI가 연결됐다면 짧은 설명·더 쉽게·예시를 선택할 수 있습니다.
3. 확인 질문에 내 말로 답합니다. **아직 모르겠어요**는 현재 답변을 보존하고 재설명으로 돌아갑니다. AI 실패 시에도 답변과 원문은 유지합니다.
4. **요점노트 저장**으로 AI 설명 또는 원문 발췌, 실제 답변, 미해결 질문과 출처를 남깁니다. 같은 구간은 기존 노트를 갱신하며 기존 기록을 언어 변경만으로 자동 번역하지 않습니다.
5. **한 부분 더** 또는 **오늘은 여기까지**를 선택합니다. 재실행 후 저장된 학습을 이어갈 수 있습니다. 자유 읽기·회상·복습·자료/노트 검색·폴더도 사용할 수 있습니다.

확인 질문 피드백은 **원문 대조 안내와 정확한 원문 인용**을 제공합니다. 모델이 질문·답변과 비교할 인용을 고르며, 앱이 원문과 문자열 일치를 검사합니다. 정답·오답·이해도를 자동 판정하거나 칭찬·교정 문장을 생성하지 않습니다. 인용은 빠진 지식을 판정한 결과가 아니며, 독자가 자신의 답변과 비교할 근거입니다. PDF 그림은 원본 페이지로 확인하고, 현재 로컬 AI는 PDF 이미지 설명을 지원하지 않습니다. PDF 읽기·로컬 OCR·메모·원문 노트는 계속 사용할 수 있습니다.

짧은 확인 질문은 검증된 원문 인용을 바탕으로 만듭니다. 피드백의 안내·다음 행동은 앱의 지정 문구이며 근거 인용이 없거나 원문과 다르면 새 결과를 저장하지 않습니다. 피드백의 저장 허용 여부는 같은 모델의 의미 판정에 맡기지 않습니다. 설명의 의미 대조는 모델 판단이므로 사실 정확성을 보장하지 않습니다. 번역은 자동 정확성 승인을 하지 않는 검토 전 초안입니다. 이전 지침의 피드백은 다음 명시적 요청에서 갱신하며, 과거에 저장한 노트를 자동 수정하거나 삭제하지 않습니다.

## 학습자료 번역 초안

자유 읽기 또는 함께 공부의 **원문 번역 초안**에서 한국어/영어를 선택한 뒤 현재 읽기 구간이나 전체 자료를 번역합니다. 번역 언어는 앱 표시·학습 설명 언어와 독립적입니다. 원문과 번역을 나란히 대조할 수 있으며 원문·답변·노트·읽기 위치는 바꾸지 않습니다. 함께 공부의 현재 구간 번역은 화면의 작은 설명 부분이 속한 읽기 구간 전체를 대상으로 합니다.

번역은 연결한 Ollama 모델로 작은 부분을 순서대로 처리합니다. 전체 자료는 완료한 구간부터 저장하고 취소·실패 후 같은 모델·원문·언어·지침 버전으로 다시 실행하면 완료 구간을 재사용합니다. 저장된 번역은 서버 연결 없이도 볼 수 있습니다. 모델을 바꾸면 다음 명시적 번역 요청에서 새로 생성하며, 언어 선택만 바꾸어 자동 요청하지 않습니다. 긴 논문은 시간이 걸릴 수 있으며 취소할 수 있습니다.

번역 결과는 모두 **검토 전 초안**입니다. 현재·저장된 결과와 과거 번역에도 의미 정확성을 자동 판정하지 않는다는 안내를 표시합니다. 같은 모델의 pass/fail로 정확성을 승인하거나 저장을 거절하지 않으며, 번역문을 원문과 다시 보내 의미를 재판정하지 않습니다. 초안에는 오역·누락·가능성의 강도 변화·번역되지 않은 원문이 남을 수 있습니다. 원문과 직접 대조하세요.

코드·URL·수식·PDF 쪽 표제·문단 줄바꿈은 보호 표식으로 대체한 뒤 앱이 정확히 복원합니다. **일반 문장에 숫자가 포함된 구간은 자동 번역을 중단합니다.** 현재 설치 모델의 수치 관계 오역을 고려한 제한이며, 초안 전환 후에도 유지합니다. 코드·URL·수식 안의 숫자와 숫자만 있는 구간은 그대로 보존합니다. 모델이 표식을 바꾸거나 누락하면 해당 구간을 저장하지 않습니다. JSON·길이·완료 상태와 목표 언어의 문자 검사를 통과해야 초안으로 저장합니다. 문자 검사는 언어·의미의 정확성을 보장하지 않습니다.

한국어 언어 검사에 실패하면 같은 원문에서 한 번만 다시 생성하며, 잘못된 글자를 삭제해 통과시키지 않습니다. 생성 입력이 문맥 한도를 넘으면 한 번 더 작은 조각으로 나누며, 계속 실패하면 완료한 이전 구간을 보존하고 중단합니다. 재생성은 구간별 180초 제한과 취소 신호를 공유합니다.

새 지침의 번역 요청은 이전 지침의 캐시를 재사용하지 않으며, 이미 저장한 번역을 자동 삭제하거나 바꾸지 않습니다.

PDF는 추출/OCR 텍스트만 번역하며 빈 페이지는 건너뜁니다. 그림·표·수식의 배치를 복원하지 않습니다. 로컬 모델이 문장을 누락하거나 전문용어·코드·수식을 잘못 번역할 수 있으므로 원문과 대조하세요. 번역문을 정답이나 학습 평가 근거로 자동 사용하지 않습니다. 브라우저 미리보기에서는 새 번역 생성이 지원되지 않습니다.

## 로컬 AI

현재 연결은 **사용자가 이미 준비한 Ollama 텍스트 모델**입니다. 구독 로그인·SDK·브랜드·외부 AI API 키는 포함하지 않습니다. 서버/모델 설치·다운로드·유료 전환을 앱이 자동 수행하지 않습니다.

앱의 로컬 AI 연결 패널에서 `127.0.0.1` 또는 `::1`과 포트를 입력하고 서버 연결 → 모델을 직접 선택하세요. 기본 포트는 11434입니다. 재시작 후 연결 주소와 모델 선택은 보존하지만 자동 서버 조회/추론하지 않으므로 연결 상태를 다시 확인합니다.

- API 계약 fixture 범위는 Ollama **0.12.0 / 0.24.0 / 0.40.4**입니다. 다른 버전은 확인 전 차단하며 구버전으로 내릴 것을 권장하지 않습니다. 실제 설치 버전이 다르면 별도 호환 검증이 필요합니다.
- GGUF 텍스트 모델의 digest·completion·context·remote metadata를 요청 전에 확인합니다. cloud·원격·확인 불가 모델, 이미지 요청과 임의 서버 URL은 거절합니다.
- 현재 원문·질문·답변 등을 선택한 로컬 서버로 보냅니다. 실패·시간 초과·잘못된 JSON/인용·취소 시 기존 기록을 보존하고 다른 제공자나 유료 API로 자동 전환하지 않습니다.
- localhost와 metadata 검사만으로 완전 오프라인을 보장하지 않습니다. Ollama cloud 기능·서버 로그·프록시 설정은 사용자가 관리하며 실제 오프라인 동작·모델 품질·메모리와 지연시간은 별도 검증이 필요합니다.

모델이 없거나 서버가 꺼져 있어도 AI 없는 학습은 사용할 수 있습니다. 다른 버전에 저장한 모델 선택·설명·답변·노트는 지우지 않습니다. 지금 제공하지 않는 과거 모델은 사용 불가로 유지하고 사용자가 새 로컬 모델을 직접 선택합니다.

## 한국어와 영어

앱 표시 언어와 새 학습 구간의 설명 언어를 독립적으로 설정합니다. 현재 구간은 시작할 때의 설명 언어를 유지하며 변경된 기본값은 다음 구간부터 적용합니다. 기존 원문·질문·답변·노트·복습 시각을 자동 번역하거나 덮어쓰지 않습니다. UI 언어 변경만으로 AI 요청을 실행하지 않습니다.

## 저장·백업·삭제

기본 macOS 저장 위치는 `~/Library/Application Support/Swallow`이며 `SWALLOW_DATA_DIR`에 절대 경로를 지정하면 달라집니다. SQLite·PDF 복사본·초안·백업은 앱 자체에서 암호화하지 않습니다. 문서 삭제 후 PDF·미저장 PDF 메모·legacy 파일·백업은 남을 수 있습니다. 보관은 압축 저장이며 삭제가 아닙니다.

백업은 앱을 완전히 종료한 뒤 DB·PDF·필요한 legacy/백업을 함께 안전한 로컬 위치에 복사하세요. 현재 저장소를 빈 파일로 덮어쓰거나 인증/모델 파일을 임의 삭제하지 마세요. 정확한 전송·삭제 범위와 관리 절차는 [개인정보 안내](PRIVACY.md)를 확인하세요.

## 검증과 공개 소스 준비

```sh
npm run check        # 전체 테스트 + PDF/타입/Vite/Electron/preload 빌드
npm run source:check
npm run source:prepare
```

`source:check`는 working tree의 명시적 소스 목록에서 구독 의존성·금지 파일·symlink·제한된 민감 패턴과 공개 문서 링크를 확인합니다. `source:prepare`는 통과한 파일만 `artifacts/public-source/`의 새 폴더에 복사하고 파일별 SHA-256 manifest를 만듭니다. Git 이력·node_modules·사용자 DB·인증·내부 계획·설치본은 복사하지 않으며 commit/push/업로드도 하지 않습니다. 테스트/빌드와 최종 사용자 검토는 별도이며, 패턴 검사가 모든 비밀을 증명하는 것은 아닙니다.

Electron UI 검증 스크립트는 선택 도구 Playwright를 사용합니다. [별도 도구 폴더에 준비하는 방법](CONTRIBUTING.md#ui-검증-준비)을 참고하거나, 이미 설치된 모듈의 절대 경로를 `SWALLOW_PLAYWRIGHT_MODULE`로 지정하세요. 합성 localhost 서버/임시 저장소 시험과 실제 모델·설치본 검증은 구분합니다.

빌드 후 기존 Playwright로 UI 전체 회귀를 실행하려면:

```sh
export SWALLOW_PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs
(for flow in study folders update ollama i18n translation pdf; do
  node "scripts/test-${flow}-ui.mjs" || exit 1
done)
```

이 시험은 임시 앱 저장소와 합성 AI/업데이트 응답, 저장소 안의 PDF 예제를 사용합니다. 계정·모델 다운로드·실제 업데이트 설치는 하지 않습니다. 공부 UI 시험은 설치된 macOS 음성이 사용 가능하면 읽어 주기 시작/중지를 확인합니다. localhost/GUI/OCR 사용 권한이 필요하며 실패한 시험을 제외해 통과 처리하지 마세요.

문서를 추가하는 중 대상 폴더가 삭제됐다면 입력을 유지하고 다른 폴더를 선택하라는 안내를 표시합니다. 중복 폴더 이름도 다른 이름으로 바꿀 수 있도록 안내합니다. 업데이트 시험은 선택적인 음성 목록 조회가 끝난 뒤 설치를 검증하며, 진행 중 작업·답안/메모 저장 실패 시 설치를 막는 보호는 유지합니다.

## 일회성 후원 준비

Swallow는 후원 여부와 관계없이 모든 기능을 계속 무료로 제공합니다. 준비 중인 후원은 개인 개발과 유지보수를 응원하는 선택적인 일회성 지원입니다. 후원자 전용 기능·선행 배포·우선 지원·광고·이름이나 로고 게재를 제공하지 않으며, 특정 기능 개발이나 완료 시점을 약속하지 않습니다.

현재 후원 접수는 시작하지 않았습니다. 가입과 지급 설정을 마치고 일회성 결제 조건을 확인한 뒤 안내하겠습니다. 앱 사용을 위해 후원하거나 결제 정보를 입력할 필요는 없습니다.
